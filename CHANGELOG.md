# Changelog
## 1.1.0
- Added FLICK support as an alternative to SKSE Menu Framework.
- Added automatic frontend selection and a `Prefer FLICK` setting. The Journal opens the selected frontend.
- Fixed Alternate Perspective custom dialogues getting stuck on `Loading...`.
- Fixed unavailable MCM dropdowns in both frontends.
- Added support for the MCM Helper 1.6.3 Skyrim SE 1.5.97 backport.
- Fixed SKSE Menu Framework version detection and raised the minimum required release to 3.18.
- Added configurable FLICK page selection: sidebar, top panel or dropdown. Sidebar is the default.
- Added aliases and optional alphabetical MCM groups in FLICK.
- Added an `MCM Bridge` group with Settings, Browser and FLICK settings.
- Improved FLICK text wrapping, content scaling, sliders, dropdown indicators and section separators.
- Fixed missing page labels, clipped reset buttons and reset-button alignment in FLICK.
- Removed obsolete Unlocked integration, Open Original navigation and legacy host paths.

## 1.0.0
- Initial release.
